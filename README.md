# Manga Hub

Личная библиотека манги: произведения из разных источников, прогресс чтения и быстрый переход к продолжению.

## Первая версия

- Библиотека со статусами чтения, оценками и заметками.
- Учёт прочитанных глав и ссылок на источники.
- Импорт и экспорт библиотеки.
- Интеграции с выбранными площадками в рамках разрешённых способов доступа.

## Разработка

Проект на начальном этапе. Стек пока не выбран, приложение ещё не создано.

Разработка начинается локально на macOS, без обязательного Docker и отдельного сервера.
