# Manga Hub

Сайт для поиска манги и сравнения её доступности на разных площадках.

## Первая версия: каталог без регистрации

- Поиск по названиям и их вариантам, фильтры по источнику и языку.
- Общая карточка произведения со ссылками на площадки.
- Сведения о главах, доступности и времени последней проверки.
- Источники подключаются после проверки условий автоматизированного доступа и использования данных.

Кандидаты для русского каталога: MangaLib, ReManga, ReadManga и названный пользователем IncStory (предположительно InkStory; адрес требует подтверждения). Для английского каталога: MangaRead (предположительно mangaread.org) и WEBTOON. Это список для проверки, а не перечень уже работающих интеграций.

## План и устройство

- [План первых этапов](docs/PLAN.md)
- [Архитектура и структура каталогов](docs/ARCHITECTURE.md)
- [Проверка источников и условий доступа](docs/SOURCES.md)

Рабочая архитектура: Next.js + TypeScript, PostgreSQL с первого дня, Drizzle для схемы и миграций. Это обычный сайт в браузере; отдельный мобильный или настольный клиент не входит в первую версию.

Разработка начинается на macOS с нативным PostgreSQL, без Docker и аренды сервера. Пока в репозитории только документация: команды запуска и зависимости появятся при создании кода.
